# Кейс 1. Торговля и транспорт России, 2015–2024 гг.

Статистический анализ двух отраслей национальной экономики: динамика, структура, прогноз, корреляция и регрессия.

Махно Г. О., группа УСБО-04-24.

## Состав

| Папка | Что внутри |
|---|---|
| `presentation/index.html` | Презентация, 14 слайдов, с анимацией. Работает без интернета: открыть двойным щелчком, листать стрелками, F11 — полный экран |
| `presentation/*.pdf` | Та же презентация в PDF, 14 страниц 16:9 |
